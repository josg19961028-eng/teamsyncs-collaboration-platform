팀의 모든 일정과 업무를
하나로 싱크하다.

TeamSync는 캘린더, 실시간 채팅, 칸반보드, 회의록을 하나의 플랫폼에 통합하여
팀의 의사결정 속도와 효율성을 비약적으로 높이는 협업 웹 서비스입니다.

📅
Today 스케줄 5건 예정됨
💬
실시간 알림 멘션 도착
성공적인 협업을 위한 올인원 솔루션
팀원들과 함께 효율을 극대화할 수 있는 강력한 기능들을 제공합니다.
📅

스마트 캘린더

FullCalendar.js를 활용하여 전체 팀 일정 및 개인 일정을 통합 시각화합니다. 일정 참여자를 직접 초대하고 수락 상태를 실시간 트래킹할 수 있습니다.

📋

칸반 보드

드래그 앤 드롭 방식을 채택하여 할 일, 진행 중, 검토, 완료 단계를 직관적으로 매핑하고 팀별 전체 업무 진행률 바를 한눈에 볼 수 있습니다.

💬

WebSocket 채팅 & 멘션

STOMP 기반의 채널 격리 대화방을 구현했습니다. @팀원 태그 멘션을 하면 멘션 테이블과 알림 서버에 즉시 전송되며 푸쉬 알림을 발송합니다.

📝

연동형 회의록

특정 일정과 직접 매핑하여 상세한 회의 내용을 작성하고 보관할 수 있습니다. 작성 완료 시 정제된 레이아웃의 PDF 보고서로 내보낼 수 있습니다.

🗂️

계층형 폴더 보관함

부모-자식 자기참조(Oracle START WITH CONNECT BY) 모델을 활용하여 구글 드라이브 같은 계층 폴더 시스템을 완벽히 재현했습니다.

📊

대시보드 시각화

Chart.js 라이브러리를 이용하여 월별 주간 일정, 팀원별 칸반 기여율, 채널별 채팅 활성 비율 등을 한눈에 그래프로 제공합니다.

Team Calendar

캘린더 일정을 통한 시각적 일정 공유

팀 전체의 스케줄을 한 눈에 확인하고, 날짜 클릭 시 나타나는 모달 창에서 간편하게 일정을 추가 및 수정할 수 있습니다.

1FullCalendar 기반 월간/주간/일간 뷰 전환 스위치
2특정 팀원들을 선택해 일정에 초대하는 동적 동기화 기능
3초대받은 멤버들의 수락 및 거절 상태 실시간 모니터링
Task Kanban Board

드래그 앤 드롭을 이용한 유연한 업무 프로세스

스마트한 칸반보드 모듈을 탑재하여 팀 업무 진행 상황을 4단계('할 일' ➔ '진행 중' ➔ '검토 중' ➔ '완료') 컬럼 구조로 정형화했습니다.

1업무 카드를 마우스로 드래그하여 상태를 직관적으로 제어
2카드 내부 세부 체크리스트 완료 시 진행률 바 자동 계산 반영
3마감기한 설정 및 태그 기능으로 중요 업무 가독성 고도화
Real-time Messaging

WebSocket 기반 실시간 소통 인프라

STOMP 프로토콜로 각 채널방을 격리하여 빠른 전송 속도를 자랑합니다. 대화창에서 파일 첨부 및 멘션 호출이 자유롭게 결합되어 있습니다.

1@팀원을 작성해 특정 멤버에게 타겟 푸쉬 알림 발송 가능
2채팅창 내 이미지 및 다큐먼트 파일(최대 10MB) 즉시 전송
3답글 달기 기능을 제공하여 이전 문맥과의 연속성 보장
Archive & Minutes

드라이브형 통합 파일 보관함 및 회의록

채팅이나 회의에서 파생된 결과물들을 한 눈에 모아보고 트리 형태로 관리할 수 있는 가상 드라이브 구조를 완벽하게 정형화했습니다.

1계층형 쿼리를 활용한 파일 보관 폴더 생성 및 이동 트리 뷰
2일정과 매칭된 회의록 생성 및 가독성 높은 PDF 다운로드 제공
3업로드 일시, 용량, 업로더의 족보를 트래킹하는 메타 인포 노출
Structured Database

엄격한 DB 모델링과
정규화를 통과한 설계

안정적인 협업 솔루션을 실현하기 위해 멘션 테이블, 파일 관리, 읽음 확인 뱃지를 구현할 복합키 테이블 및 자가 참조 계층 폴더 설계에 이르기까지 꼼꼼한 Oracle 모델링 규칙을 수립했습니다.
